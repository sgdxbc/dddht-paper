We further categorize nodes into different size classes and the average capacity frequencies are shown in \autoref{fig:freq-class}.
The current DHT overlooks the heterogeneous size of the storage providers, so capacity frequency decreases in logarithmic speed from one size class to another.

As the opposite, DDDHT's capacity frequency is balanced across size classes.
The CDF is also without the long tail.
