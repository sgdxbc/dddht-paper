\section{Conclusion}
\label{sec:concl}

In this work, we propose \sys, a novel decentralized storage system with guaranteed data durability even in the presence of strong adversaries.
\sys challenges prior trade-offs in storage scalability and strong Byzantine fault tolerance.
It does so by storing fragments of each object to all storage nodes, while maintaining constant per-object redundancy when the system scales.
\sys leverages rateless erasure code and a randomized, decentralized fragment distribution protocol to avoid costly BFT coordination.
We also develop a new Optimal Regeneration Code and a self-certifying fragment scheme to minimize object repair overhead.
Simulation and global-scale experiments show that \sys provides stronger tolerance to adversarial behaviors, while attaining comparable performance, storage efficiency, and object repair cost.
