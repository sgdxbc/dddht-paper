We propose \sys, a novel decentralized storage system that can practically tolerance Byzantine fault.
\sys deploys rateless erasure code and VRF to make data location completely random and unpredictable,
without any centralized coordinator or complex p2p cooperation.
We provide a proof of correctness to show the system always ensure safety invariant.
We implement \sys and deploy it in a world-wide system.
Various benchmarks show \sys can achieve equal or better performance compare to existing decentralized storage system,
with extra durability that none the existing system provides. While the overhead of repair traffic is acceptable.
The \sys will enable more versatile decentralized application to be developed and provide a solid fundamental storage service to them.
