\begin{abstract}

The lack of centralized control, combined with dynamic adversarial behaviors, makes data durability a challenge in decentralized storage systems.
In this work, we introduce a new storage system, \sys, that offers strong data durability guarantees in a fully decentralized, permissionless setting.
\sys eschews the traditional approach of selecting placement groups with local failure correlation, which has shown to have fundamental durability limitations in decentralized deployments.
Instead, \sys distributes all objects to every storage nodes in the system, eliminating data loss due to correlated failures or adversarial behaviors.
To scale the system storage capacity, \sys applies rateless erasure code to bound the redundancy level of each object but without compromising durability.
We also leverage the rateless property of the code to fully decentralize the object encoding and decoding process without costly BFT consensus.
Moreover, we develop a new coding scheme based on Luby Transform codes that achieves high repair efficiency and tolerates Byzantine behaviors.
Simulations and large-scale EC2 experiments demonstrate that \sys provides close-to-ideal mean-time-to-data-loss (MTTDL) with low storage redundancy, scales to more than 10,000 nodes, and attains performance comparable to prior storage systems with weak durability guarantees.

\end{abstract}
